# EXP-3-PROMPT-ENGINEERING

# Aim

Evaluation of 2024 Prompting Tools Across Diverse AI Platforms: ChatGPT, Claude, Bard, Cohere Command, and Meta AI.

The aim of this experiment is to compare the performance, response quality, user experience, and effectiveness of prompting tools across different AI platforms. A common use case is selected and tested on each platform to analyze how well they understand prompts and generate useful responses.

# AI Tools Used

## ChatGPT

ChatGPT was used to generate responses for the selected test scenario. It demonstrated strong conversational abilities, detailed explanations, and well-structured outputs suitable for educational and professional tasks.

## Claude

Claude was evaluated for its ability to generate safe, detailed, and context-aware responses. The platform was tested using the same prompts to compare consistency and response quality.

## Bard (Google Gemini)

Bard was used to analyze how Google's AI platform responds to prompts involving summarization and technical explanations. Its ability to provide current and informative responses was examined.

## Cohere Command

Cohere Command was tested for text generation, summarization, and question-answering capabilities. Its response relevance and accuracy were evaluated using the selected use case.

## Meta AI

Meta AI was included in the experiment to assess its conversational capabilities and performance in understanding and responding to user prompts effectively.

# Algorithm

## Step 1: Select a Use Case

A common use case such as text summarization or answering a technical question was selected. This ensured that all AI platforms were evaluated under the same conditions.

## Step 2: Prepare the Prompt

A standard prompt was created and used across all platforms. Using the same prompt ensured fairness and consistency during comparison.

## Step 3: Execute the Prompt

The prompt was entered into ChatGPT, Claude, Bard, Cohere Command, and Meta AI. The responses generated by each platform were collected for analysis.

## Step 4: Evaluate Responses

The outputs were evaluated based on accuracy, completeness, clarity, response time, and user experience. Observations were recorded systematically.

## Step 5: Compare Performance

The responses from all platforms were compared to identify strengths and weaknesses. Special attention was given to response quality and prompt understanding.

## Step 6: Document Findings

The observations and comparisons were compiled into a report for interpretation and conclusion.

# Prompt

## Test Prompt Used

"Explain the concept of Machine Learning, its major types, real-world applications, advantages, and challenges in approximately 300 words."

The same prompt was provided to all five AI platforms. This ensured that differences in output quality were due to platform capabilities rather than prompt variations.

# Output

## ChatGPT Output

ChatGPT generated a comprehensive and well-structured explanation covering all aspects of Machine Learning. The response was detailed, logically organized, and included relevant examples and practical applications.

## Claude Output

Claude produced a detailed and context-rich response with strong readability. The explanation was accurate and easy to understand, making it suitable for educational purposes.

## Bard (Google Gemini) Output

Bard generated an informative response with good coverage of Machine Learning concepts. The output emphasized practical applications and provided concise explanations.

## Cohere Command Output

Cohere Command delivered a clear and relevant response. While the information was accurate, the explanation was comparatively shorter and less detailed than some other platforms.

## Meta AI Output

Meta AI produced a user-friendly response with understandable explanations. The content was relevant and useful, though it provided less depth in certain technical areas.

# Output & Interpretation

## Accuracy

All platforms provided accurate information regarding Machine Learning concepts. ChatGPT and Claude demonstrated the highest level of detail and conceptual clarity.

## Completeness

ChatGPT covered all requested aspects comprehensively, including types, applications, advantages, and challenges. Claude also performed well, while other platforms provided comparatively concise responses.

## Clarity

The responses from ChatGPT, Claude, and Meta AI were highly readable and well-organized. Their explanations were suitable for both beginners and intermediate learners.

## User Experience

The user experience was generally positive across all platforms. ChatGPT and Claude provided the most structured and engaging interactions, while Bard offered useful real-world context. Cohere Command and Meta AI delivered efficient and straightforward responses.

## Comparative Analysis

The experiment revealed noticeable differences in response depth and presentation style. ChatGPT and Claude generated more comprehensive outputs, while Bard focused on practical information. Cohere Command and Meta AI performed effectively but produced comparatively shorter responses.

# Result

The experiment was successfully completed by evaluating prompting tools across ChatGPT, Claude, Bard (Google Gemini), Cohere Command, and Meta AI. The results showed that all platforms were capable of generating useful responses; however, ChatGPT and Claude provided the most detailed, accurate, and structured outputs. The study confirmed that platform capabilities significantly influence response quality, user experience, and overall effectiveness in prompt-based interactions.
